# A sacudida do cachorro

Material da **ficha nº 07** de [`ideias/`](../../ideias/crianca-e-mediador/07-a-sacudida-do-cachorro.md).

Cinco minutos, sempre depois de um momento difícil. Repetido até juntar umas
dez linhas.

> **Leia [Conduzir sem induzir](../conduzir-sem-induzir/) antes.**
> É atividade de bioenergia.

| peça | para quem | como usar |
|---|---|---|
| [`atividade`](atividade.md) | criança | ler uma vez, no começo |
| [`folha-de-registro`](folha-de-registro.md) | criança | uma linha por vez |
| [`guia-do-mediador`](guia-do-mediador.md) | adulto | ler antes de oferecer a primeira vez |

## O que a distingue

É a única atividade do conjunto que entrega à criança um **recurso de
autorregulação** — e, junto, uma forma de **verificar se ele funciona para
ela**. A nota "antes" é o que faz a segunda parte existir; sem ela sobra só a
impressão de melhora.

Como em *A bola entre as mãos*, algumas repetições são feitas **sem** o
exercício, só sentando em silêncio pelo mesmo tempo, e marcadas com **C**. Se as
duas colunas derem notas parecidas, esse é o resultado.

## Cuidado de condução

O guia insiste num ponto: **não ofereça no meio de uma crise nem logo depois de
uma bronca.** Nessas horas a técnica vira castigo disfarçado, e a criança passa
a associá-la a punição.
