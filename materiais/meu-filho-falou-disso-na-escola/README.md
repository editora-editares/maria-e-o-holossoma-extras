# "Meu filho falou disso na escola"

Material da **ficha nº 18** de [`ideias/`](../../ideias/pais-e-educadores/18-meu-filho-falou-disso-na-escola.md).

| peça | para quem | como usar |
|---|---|---|
| [`roteiro`](roteiro.md) | adulto | ler quando o assunto aparecer, ou um pouco antes |

Trata da cena que o livro mostra duas vezes: a criança fala do assunto com os
colegas e a conversa dá errado. O objetivo é sustentar o respeito a quem pensa
diferente **sem desautorizar a criança e sem armá-la** para a próxima
discussão.

Termina apontando para
[O que o amparador não é](../o-que-o-amparador-nao-e/), que é o que a escola
costuma perguntar em seguida.
