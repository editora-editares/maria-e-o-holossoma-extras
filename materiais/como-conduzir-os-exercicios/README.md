# Como conduzir os exercícios

Material **transversal**: não deriva de uma ficha de [`ideias/`](../../ideias/),
vale para todas as vinte.

Existe porque as fichas dizem cada uma o que fazer no seu caso, e nenhuma diz
o que é comum a todas: a inversão pedagógica que o livro pede, a sequência de
uma sessão, a ordem em que os materiais se encaixam e o limite do papel do
adulto.

## As duas peças

| peça | quando |
|---|---|
| [`instrucoes-didaticas`](instrucoes-didaticas.md) | ler **uma vez**, antes do primeiro exercício |
| [`cartao-do-mediador`](cartao-do-mediador.md) | levar para a sessão, uma página |

A divisão é o ponto: ninguém lê seis páginas com uma criança esperando ao
lado. O documento longo forma; o cartão opera.

## O que este material não repete

- **O que fazer em cada exercício** — está na ficha de cada um.
- **Condução de atividade bioenergética**, o que não perguntar e o que fazer
  se a criança relatar algo que a assuste — está na ficha nº 20,
  *Conduzir sem induzir*, para a qual as instruções remetem.
- **Como preencher a ficha de experimento** — está em
  [`../minha-ficha-de-experimento/`](../minha-ficha-de-experimento/).
